# Figure-generation scripts

Both scripts write directly into `/home/claude/edge_defense_2/figures/`
(overwriting the PNGs currently embedded in the paper).

## Run everything (all 9 figures, 600 dpi)

```
python3 /home/claude/edge_defense_2/figure_scripts/regen_all_figures.py
```

Requires: `matplotlib`, `numpy`, `pandas`, `shap` (only Fig. 3 needs
`shap`, and it also needs `model_C.pkl` + `canonical/e_te.csv` /
`canonical/i_te.csv` to be present under `/home/claude/edge_defense_2/`
-- Fig. 3 recomputes real SHAP values on the fly, it does not hardcode
any plotted numbers).

Produces:
- `fig1_architecture.png` -- pipeline/architecture diagram (Fig. 1)
- `fig_cross_domain_heatmap.png` -- train×test AUC heatmap (Fig. 2)
- `fig_shap_combined.png` -- SHAP summary plots (Fig. 3)
- `fig_evasion_vs_budget.png` -- evasion rate vs. perturbation budget (Fig. 4)
- `fig_edge_latency.png` -- per-tier latency bars (Fig. 5)
- `fig_lit_comparison.png` -- comparison with existing work (Fig. 6)
- `fig_latency_comparison.png` -- latency literature comparison (Fig. 7)

(`fig_shap_beeswarm_enterprise.png` / `fig_shap_beeswarm_iot.png` are
older standalone SHAP plots superseded by the combined `fig_shap_combined.png`
and are not regenerated by this script.)

## Run just the architecture diagram (Fig. 1)

```
python3 /home/claude/edge_defense_2/figure_scripts/fig1_architecture_only.py
```

No model/data dependency -- pure matplotlib, safe to tweak colors/labels
and rerun quickly. The full script above contains the identical Fig. 1
code, so edit one and copy the change into the other if you want both
to stay in sync.

## What changed vs. the originally-delivered figures

- **Fig. 1** was redrawn with drop-shadowed "cards," colored header
  bars per pipeline stage, a left-hand stage rail (DATA / UNIFY / TRAIN
  / ANALYZE / MONITOR), and real dataset-size annotations pulled from
  Table II (308,877 Enterprise rows; 297,091 of 46,776,697 IoT rows;
  15-feature canonical schema) instead of a plain box-and-arrow layout.
- **Fig. 5**: legend moved from `upper left` to `upper center` and the
  y-axis limit raised to 78 so the legend box no longer overlaps the
  "Predict only" p99 bar (53.61 ms).
- **Fig. 7**: y-axis limit raised to 130 (was implicit/tight around 50)
  so the "50" value label above Wijethilaka et al.'s bar is no longer
  clipped at the top of the plot.
- All figures bumped from 300 dpi to 600 dpi.

## Data provenance (why the numbers are trustworthy)

Every plotted number traces to one of these places:
- Figs. 2, 4, 5, 6, 7: hardcoded arrays in the script, but each value is
  copied from this project's own result files (`rescale_evasion_n500_results.json`
  for the n=548 adversarial-evasion numbers; the edge-latency benchmark
  log for Table IX / Fig. 5 / Fig. 7; the model evaluation script output
  for the AUC heatmap) or, where marked, from the cited external paper
  (Elangovan et al. [4], Pawlicki et al. [7], Rajhans & Khawarey [14] in
  Fig. 6b) -- never invented.
- Fig. 3 is not hardcoded at all: it loads `model_C.pkl` and the actual
  canonical test CSVs and computes SHAP values live via
  `shap.TreeExplainer`, so it will reflect whatever model/data is on
  disk if either changes.
